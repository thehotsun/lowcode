# 移动端第四期：顶部筛选与排序工具条

## 已确认的口径决策
1. **排序对齐桌面现状**：后端排序。面板选字段+升降 → `externalParams.sqlConfig = {sort:[{field, order:"asc"|"desc"}]}` → 替换式查询；取消排序 → `{sort:[]}`。与桌面 939194c 后行为完全一致（`refreshData` 持久化语义：externalParams 持久、翻页/后续查询不丢）。方案文档中"仅本地排序、优先 sort-method"的过时表述同步修订。
2. **工具条尾部加"重置"入口**：`tableAttrs.onResetBtnEvent` 有配置时 `str2Fn(...).call(this, cloneDeep)` 完全接管（桌面 `handleFilterReset` 同语义）；否则默认重置 = `resetSearchForm()` + 清 `multiFieldSearch` + 收起面板 + `loadFirst()`（排序不动，对齐桌面 `handleReset`；取消排序走排序面板）。预览态/禁用态不执行。
3. **本地模式不实现**：桌面本地过滤/分页仅存在于 vform 从表（`renderMode===0`，依赖 `getWidget` inject），移动端无该场景（未 inject `getWidget`），文档标注为不适用。
4. **列筛选不发明远端协议**：列 `filters`/`filtersConfig` 选项与搜索控件统一入口，选中值经 `searchForm` 同通道提交（与搜索控件同形状的等值条件），文档记录此口径。
5. **实现位置**：延续单文件模式，在 `packages/mobileTable/index.js` 新增 `renderFilterBar` 渲染方法组（R7 已注明单文件为既定实现暂态；R14 的 `MobileFilterBar.vue` 名称在文档中调整为方法组口径）。

## 实现步骤

### 1. 配置解析与状态
- `InstanceData` 新增：`fuzzyFieldSearchConfig`（默认 `{placeholder:"", searchFieldList:[]}`）、`activeFilterKey`（同屏单面板）、`sortState:{field,order}`（UI 镜像）、`filterOptionCache`（按 fieldCode 缓存远程选项 `{status,list}`）、`panelExpandedMap`（每字段"展开更多"态）。
- `parseTableConfig` 解析顶层 `fuzzyFieldSearchConfig`（merge 默认值容错，当前未解析）。
- `composeFields` 的 flat 项补 `sort: Boolean(item.sort)`（排序面板数据源）。
- 新增 computed：
  - `fuzzySearchEnabled`：`searchFieldList.length > 0` 才渲染模糊框。
  - `filterEntries`：有效筛选入口有序列表。来源 A = `isSearchWidget===true` 且 `searchWidget` 枚举可解析（与 `composeSearchParams` 同判定）；来源 B = 列 `filters`（字符串 `str2obj` 得 `[{text,value}]`）/`filtersConfig.customHandler`/`filtersConfig.isFilter`。同 fieldCode 合并为一个入口，面板类型以 searchWidget 为准、filters 选项并入选项列表去重。按 `searchWidgetConfig.sortNumb` 升序稳定排序。**不按 show 过滤**（与桌面搜索区独立于列显隐一致）。`extraOption` 为字符串时 `str2obj` 还原（对齐桌面渲染端）。
  - `sortableFields`：`allDisplayFields.filter(f => f.sort)`。
- 工具条渲染条件：有模糊框或任一入口或排序字段，才渲染工具条。

### 2. 工具条 UI（render 方法组）
- `render()` 在 `.mt-scroll` 之前插入 `renderFilterBar()`（工具条固定顶部不随卡片滚动）。
- 模糊搜索行：`el-input`（prefix 搜索图标、clearable、placeholder）绑定 `multiFieldSearch`（输入 trim，桌面同款）+ 回车（`nativeOn` keydown 13）与"搜索"mini 按钮触发查询；`onClear` 同触发。
- 入口行：横向滚动 pill 列表，每字段"`fieldName` ▾"，有选中值时高亮并显示摘要；排序入口居末（无选中="排序 ▾"，有选中="字段名 ↑/↓"）；尾部"重置"入口。
- 面板：活动入口下方 absolute 面板 + 全屏透明 backdrop（点击收起，实现"点击面板外收起"）；`activeFilterKey` 保证同屏单面板。
- 面板按 `searchWidgetType` 分派（枚举 id：0 文本/1 数值范围/2 下拉/3 日期/4 日期范围/5 级联/6 字典）：
  - 选项列表类（列筛选来源、2 下拉、6 字典）："全部" + 单选列表（选中打勾），>8 项折叠 + "展开更多/收起"，**点选即生效**（对齐桌面 change 触发查询）。
  - 文本（0）：`el-input` + 确定/清空按钮。
  - 数值范围（1）：Start/End 两输入 + 确定/清空；两端不完整提示不提交（桌面 `isValid` 语义）。
  - 日期（3）/日期范围（4）/级联（5）：`el-date-picker`/`el-cascader`（`tagAttrs`、`extraOption.props` 透传），change 即生效。
- 排序面板：字段列表 + 升/降方向 + "取消排序"，生效即更新 `sqlConfig` 并重查。

### 3. 选项加载（对齐桌面 BaseRenderForm `disposeRequest` 语义）
- 面板首次展开按需加载并缓存（`filterOptionCache`）：
  - `request.autoFillOptions` → POST `/dyn-common/page-list/queryDictColumnDataList`（body 对齐桌面代码：`listPageId`/`idFieldName`/`titleFieldName`）。
  - `request.require && request.url` → `generalRequest(url, request.type)`（字典 url 含 dicCode；`labelTranslateType===1` 时 label 拼 `dicId-` 前缀、props 强制 `{key:"dicId",label:"cnName"}`）。
  - 静态 `extraOption.options` 直接用。
  - 列筛选选项：`filters` str2obj；`customHandler(tableData)` 面板打开时对当前数据执行（等价桌面 tableDataChangeQueue 重算语义，异常告警回退空）；`isFilter` 从当前 `tableData` 派生（非空去重、`isSplit` 按 `splitChar` 拆、`limitShowWord`/`maxlength` 仅截断显示文本）。优先级 `filters` > `customHandler` > `isFilter`。
- 选项归一为 `{value,label,children}`（filters 的 `{text,value}` 与 `extraOption.props {key,label}` 两种映射统一）。
- 预览态不发起任何选项请求（仅静态选项、面板可开合但确认不生效）；禁用态入口置灰。

### 4. 值写回与查询语义
- 统一提交入口 `applyFilterChange`：预览/禁用态拦截 → 写 `searchForm`（数值范围写 `${fieldCode}Start/End`；日期范围写数组单键——`getParams` 已实现拆分；multiple 控件提交单元素数组保持桌面请求形状；"全部"重置回 `rawSearchForm` 默认值）→ `searchWidgetConfig.listeners?.change` 以列表实例为 `this` 调用（查询先触发、原回调后执行，数值范围两端齐全才触发查询的条件语义保留）→ 收起面板 → `loadFirst()`。
- `loadFirst()` 复用意味着：`pageNo=1` 替换式查询、`requestVersion` 并发治理、第三期选择集合重锚/清空（`handleTableDataReplaced`）自动生效，无需新代码。
- 排序 `applySortChange(field, order)`：`externalParams = {...externalParams, sqlConfig: order ? {sort:[{field,order}]} : {sort:[]}}`，`sortState` 镜像更新，`loadFirst()`；加载更多自动携带排序。
- 模糊搜索：输入绑定 `multiFieldSearch`，回车/搜索/清空 → `loadFirst()`。
